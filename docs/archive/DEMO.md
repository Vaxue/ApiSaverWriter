# ApiSaverWriter 功能演示

## ✅ 已完成功能

### 1. 📚 项目管理

#### 新建小说
1. 点击「+ 新建小说」按钮
2. 填写小说标题（必填）
3. 选择类型分类（玄幻、都市、仙侠、科幻、历史、武侠、言情）
4. 点击「创建」

**效果**：
- 创建成功后自动添加到项目列表
- 显示项目卡片：标题、类型、状态、字数、更新时间
- 提供「编辑」和「大纲」操作按钮

#### 项目卡片交互
- **悬停效果**：卡片上浮 + 蓝色边框高亮
- **状态显示**：草稿 / 连载中 / 已完结
- **数据统计**：字数、更新时间

### 2. ⚡ 技能库

#### 浏览内置技能
- 10+ 预置写作技巧自动加载
- 网格布局展示技能卡片
- 每张卡片显示：
  - 技能名称
  - 评分（⭐ 0-5 分）
  - 描述
  - 标签
  - 使用次数

#### 新建自定义技能
1. 点击「+ 新建技能」按钮
2. 填写表单：
   - 技能名称（必填）
   - 分类（写作技巧/风格模板/情节模式）
   - 简短描述
   - 详细内容（必填）
   - 标签（逗号分隔）
3. 点击「创建」

**效果**：
- 新技能立即出现在技能库
- 初始评分 0，使用次数 0
- 支持后续编辑和删除

#### 技能搜索（UI 已实现，功能待接入）
- 分类筛选下拉框
- 全文搜索输入框

## 🐛 已知问题

1. **技能库初始为空**
   - 原因：未调用后端 API 加载内置技能
   - 解决：在 `loadSkills()` 中调用 TypeScript 核心库

2. **刷新榜单无实际数据**
   - 原因：返回模拟数据
   - 解决：接入 `FanqieScraper`

3. **数据不持久化**
   - 原因：仅存储在前端 state
   - 解决：接入 SQLite 数据库

4. **无删除/编辑功能**
   - 计划在下个版本实现
