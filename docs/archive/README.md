# 归档文档

本目录存放 ApiSaverWriter **早期版本（v0.1.0-alpha 前后）的历史文档**，它们描述的项目结构、完成度、测试数量与当前代码（v0.1.6）已有较大出入，仅作历史参考保留，不应作为开发依据。

当前有效文档位于仓库根目录：

- `README.md` —— 项目主文档（功能、下载、教程）
- `ARCHITECTURE.md` —— 技术架构
- `CHANGELOG.md` —— 版本更新记录
- `SECURITY.md` / `CONTRIBUTING.md` / `LICENSE`

> 注意：以下历史文档仍引用已删除的旧代码（如 `src/novel-writer.ts`、`@apisaverwriter/core`、`BookAnalyzer`、`SkillManager`、`main.rs` 等），这些模块已被 `sidecars/agent-runtime` 取代，请勿据此开发。
